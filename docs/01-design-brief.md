# Design Brief · AIRTRUTH

## Visual Direction

Maintain a crisp Swiss-editorial daylight layout (`#f3f4f2` paper surface, `#0b0f17` carbon ink, `#3a2bff` radar cobalt accent) paired with high-contrast dark telemetry panels (`#0b0f17`) for signed SHA-256 ADS-B coordinates and statutory YAML rules.

## Interactive Principles

- **Immediate Verification Feedback**: Triggering `"Airline claims weather"` animates a radar verification banner (`radar-banner flash`) highlighting both the invalidated airline excuse and the exact physical root cause.
- **Multi-Surface Proof**: Present carrier mobile UI replicas (`390x844` scaled preview frames) side-by-side with full-resolution rotation tables, METAR panels, and downloadable JSON claim packets.
